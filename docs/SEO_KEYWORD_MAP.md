## Weekly measurement workflow

1. Obtain an authorized Search Console Domain property export, or the correct URL-prefix property covering the canonical non-www HTTPS site. Never paste property credentials into this repository.
2. Export Search results query/page data for the last complete 7 days and previous 7 days, using the same country, device and search-type filters. Keep exports outside public/ and do not fabricate missing rows.
3. Join normalized query and canonical landing URL to this map. Record impressions, clicks, CTR (clicks / impressions when impressions > 0), average position and date range. Leave unavailable values blank.
4. Compare which URLs receive impressions for each cluster. If sibling service/city pages compete for the same intent, inspect actual queries and page usefulness before changing content or proposing any redirects.
5. Review support/contact conversion tracking only if separately authorized and configured. No analytics script or account integration is added here.

## Monthly measurement workflow

- Compare complete 28-day periods and year-over-year when enough history exists. Segment brand/non-brand and service/location intent, and annotate approved releases.
- Review Page indexing and Sitemap reports. Use URL Inspection on priority URLs to compare submitted versus Google-selected canonicals. Submitted does not mean indexed.
- Review organic landing-page engagement/conversions in an authorized analytics export, if available. Keep Search Console clicks distinct from analytics sessions.
- Check field Core Web Vitals when enough data exists; local builds are not proof of field performance.
- Revisit the candidate priorities from evidence. Do not automatically generate more city pages or add exact-match repetitions.
